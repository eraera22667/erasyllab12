# Қоймадағы тауар қалдығын бақылау (Өздік тапсырма)

Қойма қызметкері тауарларды тіркеп, қор мөлшерін бақылайтын Django веб-қосымшасы.

## Жергілікті іске қосу
1. `python -m venv .venv` және `.venv\Scripts\activate`
2. `pip install -r requirements.txt`
3. `python manage.py migrate`
4. `python manage.py runserver`
